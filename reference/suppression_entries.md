# Turn the entries of one page into rows

Turn the entries of one page into rows

## Usage

``` r
suppression_entries(entries = list(), list_name = character())
```

## Arguments

- entries:

  The parsed array, a list of one list per entry.

- list_name:

  The list they come from.

## Value

A data frame of `lista`, `email`, `creata` and `motivo`; with no
arguments, the empty one.
