# The closed vocabulary of what the round thinks of a row

Named here for the reason
[`outcome_vocabulary()`](https://ubesp-dctv.github.io/ubep.azure/reference/outcome_vocabulary.md)
is: the CSV holds a copy, and a word added to one and not the other is a
value the live project refuses to store or one the package never emits.
The dictionary test walks both.

## Usage

``` r
seal_state_vocabulary()
```

## Value

A character vector of the three states.
