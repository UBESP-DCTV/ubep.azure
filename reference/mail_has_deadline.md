# Whether a deadline was handed over, so that a message can say it

Whether a deadline was handed over, so that a message can say it

## Usage

``` r
mail_has_deadline(deadline)
```

## Arguments

- deadline:

  What
  [`mail_first_signin_deadline()`](https://ubesp-dctv.github.io/ubep.azure/reference/mail_first_signin_deadline.md)
  returned, or `NULL`.

## Value

`TRUE` when there is a date to print.
