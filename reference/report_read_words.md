# Say when the state was read, in both languages

Say when the state was read, in both languages

## Usage

``` r
report_read_words(period)
```

## Arguments

- period:

  What
  [`report_month()`](https://ubesp-dctv.github.io/ubep.azure/reference/report_month.md)
  answered.

## Value

A list of two strings, `it` and `en`, without the next report.
