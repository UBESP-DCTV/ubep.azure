# Join words the way a sentence lists them

Join words the way a sentence lists them

## Usage

``` r
report_join(words, conjunction)
```

## Arguments

- words:

  A character vector.

- conjunction:

  The word before the last item, `"e"` or `"and"`.

## Value

One string: `"a"`, `"a e b"`, `"a, b e c"`.
